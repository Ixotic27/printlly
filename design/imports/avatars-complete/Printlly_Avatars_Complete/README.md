# Printlly complete profile avatar pack

18 preset avatars: the original 6 plus 12 new portraits representing a range of ethnicities, skin tones and hairstyles in the same illustrated style.

## Upload to Figma

1. Extract this ZIP.
2. Open the avatars-png folder.
3. Drag all 18 PNG files into your Figma file, or use Place image.
4. Use equal width and height. Suggested avatar display sizes: 40, 48, 64 or 80 pixels.

Each PNG is a square RGBA image with transparent corners around a lavender circular background. Keep the original resolution; Figma will scale it for display.

Overview.png is a labeled preview, not an individual avatar. The JSON files document the assets and generation prompts; they do not need uploading to Figma.

All portraits are fictional preset illustrations. Users can choose any avatar; the numeric IDs do not assign identity or ethnicity to app users. These assets are static profile images.
