# Printlly role illustrations

Five separate 1024 x 1536 full-body PNG illustrations with transparent alpha, matching the cream, purple, apricot and lime human character style. Generated using built-in image generation.

- user-customer.png: customer onboarding, user profile, upload or pickup guidance.
- student-v2.png: revised student; rounder friendly facial features, stronger outlines and simpler stance, matched to the approved vendor style. Replaces the rejected student draft.
- vendor.png: vendor sign-in, partner onboarding and print-shop guidance.
- admin.png: admin sign-in, review dashboard and management guidance.
- support.png: help centre, support contact and recovery guidance.

Use contain/FIT and scale uniformly. Overview.png shows the actual cutouts over the product cream background. These are static PNG illustrations for manual upload; they have not been placed into Figma.

Generation brief: use approved human role images as style references; preserve aubergine outlines, softly shaded cartoon proportions, apricot skin, cream/purple/lime clothing, natural hands and full-body framing. Give each role appropriate phone, papers, clipboard/tablet or headset. No scenery, text, logos or watermark; transparent background. Student revision uses the approved vendor as the style master to replace the elongated, angular student draft.
